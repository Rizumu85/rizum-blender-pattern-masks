Install and first mask

Install, then bake a stitch mask along a hem.

Install

  • From Blender, with updates: Edit › Preferences › Get Extensions › Repositories › + › Add Remote Repository…, paste the address below, then search Pattern Masks and install.
  • From a zip: Get Extensions › ▾ › Install from Disk…

https://rizumu85.github.io/rizum-blender-pattern-masks/extensions/index.json

  1. 1Pattern Masks tabPress N in the 3D View to open the sidebar, then click this tab.
  2. 2The panelThe layer list on top, then marking edges and corners, the selected layer's settings, and the bake.

Add a stitch layer

Each pattern is a layer in the list: as many Stitches, Line Art and Grid layers as you like.

Give it the hem

A layer draws only along its own edges. In Blender, pick them in Edit Mode first.

Set the stitches

Sizes are real millimetres on the model, whatever its size.

  1. 1Offset InwardHow far the stitches sit from the edge.
  2. 2LengthHow long each stitch is.
  3. 3GapThe space between stitches.

Bake

Save the .blend, then press the bake button at the bottom of the panel. Each layer gives one 16-bit PNG per material, in the stitch_masks folder next to the .blend.

Paint with it

In Substance 3D Painter, import the PNG and use it as a grayscale mask on a fill layer.

Other apps and file names: Bake and use.

What it changes

Only edge and vertex attributes. Shape, UVs and materials stay as they are.
