Presets

Save a layer's settings and reuse them in any file.

Save, apply and set a default

Ctrl+Z undoes applying a preset.

  1. 1Preset buttonOpens this layer's presets.
  2. 2DefaultApplies the starred preset, or the add-on's own values when none is starred.
  3. 3NameThe name to save under.
  4. 4+Saves the current settings under that name.
  5. 5StarMakes the preset the default for new layers of that kind.
  6. 6−Deletes the preset.
